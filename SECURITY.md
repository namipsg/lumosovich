# Security policy

Security fixes are maintained for the latest published Lumosovich release. Earlier `0.x` versions may need to upgrade to receive a fix.

Please report a suspected vulnerability through [GitHub's private vulnerability reporting](https://github.com/namipsg/lumosovich/security/advisories). If that route is unavailable, email [nami.psg@gmail.com](mailto:nami.psg@gmail.com). Do not open a public issue for an unpatched vulnerability.

Include the affected version, a minimal reproduction, and the expected impact. Remove API keys, access tokens, personal data, and unrelated logs. The maintainer will triage the report privately and coordinate a fix and disclosure with the reporter.
